# Foundry V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the V1 routine/gym PWA into Foundry V2. That means eight sections, each with its own symbol (Routine, Gym, Transmutation, Stillness, Faith, Work, Screen Time, Progress), plus Insights, milestone cards, morning/evening flows and light onboarding, migrating V1 data in place.

**Architecture:**
- **Same Vite + React + TS PWA.** State stays a single versioned object in IndexedDB (`idb-keyval`, key `state`).
- **Logic in tested pure modules:** all date and streak logic lives in `src/domain/*.ts`, with Vitest tests next to each module.
- **Content as files:** content lives in `src/content/` (TS/JSON/Markdown) so Theo's material drops in without code changes.
- **Screens and symbols:** screens are in `src/screens/`, and section symbols are SVG components in `src/symbols/`.

**Tech Stack:**
- React 18.3.1, TypeScript 5.8, Vite 6, vite-plugin-pwa 1.0
- idb-keyval 6.2.1, @dnd-kit, Vitest 3.2
- **New:** `marked@15.0.12` for Insights Markdown.

**Spec:** `docs/superpowers/specs/2026-10-28-foundry-v2-design.md`

## Global Constraints

- **App name:** `APP_NAME = 'Foundry Crucible'` lives in `src/config.ts`. It's the only place the name appears in code, and the manifest reads it from there.
- **Base path:** stays `/routine-app/`. Hosting stays GitHub Pages via `./deploy.sh`.
- **Gold rule:**
  - Gold `#e8c46a` (button gradient `#f0d080 → #c9a043`, text on gold `#1a1405`) is used only for progress, completion, milestones and one primary action per screen.
  - Chrome is warm neutral: bg `#0b0b0c`, surface `#15130f`, text `#f2f2f2`, muted `#8a8578`, faint `#55524a`, line `#1d1a14`.
- **Ascent stages (fixed):** days `[1, 7, 14, 30, 60, 100, 365]`, placeholder names `Foundation, Creation, Will, Magnetism, Expression, Vision, Mastery`. Never use chakra or energy-centre wording.
- **Relapse:** a full reset to 0. No grace.
- **Morning Sit:** default 30 min, bells at start, halfway and end, screen stays awake.
- **Work inputs:** videos posted, products tested, hours worked, deep-work minutes.
- **Faith:** KJV text only, fetched from `thiagobodruk/bible` `en_kjv.json` (public domain). Scripture is never typed from memory.
- **Esoteric content:** hidden unless `settings.showEsoteric` is on.
- **Screen Time:** labelled "Preview — connects in the iPhone app". Default thresholds are foggy ≥120 min and rotting ≥240 min, with limit 120.
- **Inputs:** font-size ≥16px everywhere, to stop iOS zooming in.

## Review Focus

1. **V1 state with a renamed or missing "No PMO" habit.** Migration must not crash, and must ask once in-app (Task 1 test `migrates without SR habit`).
2. **Transmutation start in the future, or clock changes.** Elapsed time is clamped to ≥0 and never goes negative (Task 4 test `clamps negative elapsed`).
3. **Sit abandoned midway (app backgrounded or closed).** Partial minutes are logged as not completed: they count towards the Eye, but not the streak (Task 5 test `partial sit counts minutes not streak`).
4. **Day rollover at midnight while the app is open.** Today's views recompute on visibility change. The completion and streak functions take an explicit `today` (Task 3 test `completion for a past day`).
5. **Importing a V1 backup file into V2.** It runs through the same migration (Task 1 test `import v1 backup`).
